O que é CI/CD?

CI/CD é uma prática de DevOps utilizada para automatizar integração, testes e publicação de aplicações.

CI

Continuous Integration

A Integração Contínua automatiza processos como build, testes e validações sempre que um novo código é enviado para o repositório.

CD

Continuous Delivery / Deployment

Automatiza o processo de entrega e publicação da aplicação em ambientes de desenvolvimento, homologação ou produção.

GitHub Actions

GitHub Actions permite criar pipelines automatizados diretamente dentro do repositório do GitHub.
